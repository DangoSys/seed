# Seed

Seed is a single-core RV64 processor written in Chisel. The current RTL is an in-order five-stage pipeline.

- [Design specifications](specs/README.md): the intended behavior of each module.
- [Verification plans](verification-plan/README.md): how each requirement is checked, and its status.

The source and build instructions are in the [repository](https://github.com/DangoSys/seed).
